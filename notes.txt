    -> Cloud Offerings 

        -> Major Cloud providers like Amazon Web Services, Microsoft Azure, and 
        Google Cloud structure these offerings into three main categories:

            -> Infrastructure as a Service (IaaS)

            -> Platform as a Service (PaaS)

            -> Software as a Service (SaaS)

        -> Infrastructure as a Service (IaaS)

            -> IaaS provides the fundamental building blocks of computing, 
            allowing you to rent raw IT infrastructure like virtual servers, 
            storage, and networking.

            -> Raw IT infrastructure: Hardware + Hypervisor(Licensing)

                -> Hypervisor: https://www.cloud4u.com/upload/medialibrary/e69/what-is-a-virtualization-techology.png

                    -> etc

    -> In terms Of Azure Infrastructure, we have  

        -> Regions

    -> Azure Global Infrastructure - https://azure.microsoft.com/en-in/global-infrastructure/

        -> 70+ Azure regions | 400+ datacenters

    
    -> Regions 

        -> Azure Cloud Computing resources are available in different geographical locations
        which are termed as Regions 

        -> Regions are designed to service Azure Customers(your clients) that are 
        located closet to a region 

            -> https://cdn.britannica.com/96/212396-050-1FC95D3E/world-map-with-country-borders.jpg

        
        -> Availability Of Products/Services from Azure, vary from one Region To Another 

            -> https://azure.microsoft.com/en-GB/explore/global-infrastructure/products-by-region/table

        
        -> To meet specific data residency/compliance requirements.

        
        -> Pricing Varies from Region To Region 

            -> https://azure.microsoft.com/en-in/pricing/calculator/

            -> 1000 GB Storage - Estimated annual cost $262.13 (East US)

            -> 1000 GB Storage - Estimated annual cost $298.13 (South India)


    -> Availability Zones (AZ or Zone) 

        -> Availability Zones are actual Physical datacenters within Azure Regions 

        -> Within a Region, there can be Multiple Availability Zones (minimum of three )

        -> Each Zone has it's own independent components like,
        Power Supply, Networking, Cooling System, Physical Security etc 

        -> https://i0.wp.com/build5nines.com/wp-content/uploads/2018/03/az-1-zones.png?ssl=1

        -> NOTE: They ensure high availability and fault tolerance

        -> NOTE: Availability Zones are connected with Low Latency and High Speed Network Connections
