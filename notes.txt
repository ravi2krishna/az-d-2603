    -> Cloud Computing 

        -> The Cloud refers to "On-Demand" availability of Compute Power, 
        Database Storage, Applications and Other IT Resources through a 
        Cloud Platform(Azure, AWS, GCP, OCI etc) via "Internet" with 
        "Pay-As-You-Go" Pricing. 

        -> Cloud Computing can be compared to Online Ride Services 

            -> Online Ride Platforms (On-Demand)

                -> Rapido 

                -> Ola 

                -> Uber 

                -> etc 


    -> Cloud Offerings 

        -> Major Cloud providers like Amazon Web Services, Microsoft Azure, and 
        Google Cloud structure these offerings into three main categories:

            -> Infrastructure as a Service (IaaS)

            -> Platform as a Service (PaaS)

            -> Software as a Service (SaaS)

        -> Infrastructure as a Service (IaaS)

            -> IaaS provides the fundamental building blocks of computing, 
            allowing you to rent raw IT infrastructure like virtual servers, 
            storage, and networking.

            -> Raw IT infrastructure: Hardware + Hypervisor(Licensing)

                -> Hypervisor: https://www.cloud4u.com/upload/medialibrary/e69/what-is-a-virtualization-techology.png

                    -> 1. VMware (Broadcom) - vSphere Standard: $1,000 to $1,200
                    -> 2. Microsoft Hyper-V - Standard Edition: ~$380 to $500
                    -> etc 

                -> Only Pay for Hardware You use 

                    -> Hardware (https://www.myshophyd.com/)

                        -> 4 CPU - 16 GB RAM - 500 GB SSD - Networking (1GB)

                    -> https://s7280.pcdn.co/wp-content/uploads/2017/09/iaas-paas-saas-comparison.jpg.optimal.jpg
